# Живой питомец лаунчера (аквариум)

Локальный виджет на главном экране («Библиотека»): зацикленный GIF рыбы
реагирует на виртуальные подарки. Полностью офлайн — без бэкенда,
авторизации и реальных платежей.

## Файлы

| Путь | Назначение |
|---|---|
| `apps/launcher/public/pets/fish.gif` | Зацикленная анимация рыбы (локальный ассет, без внешних URL в рантайме) |
| `apps/launcher/src/features/pet/petAsset.ts` | Своя гифка: blob в IndexedDB (`chlauncher-pet`/`assets`), objectURL в рантайме |
| `apps/launcher/src/features/pet/types.ts` | Типы: `PetGift`, `PetState`, `PetEffect`, `ActiveEffect` |
| `apps/launcher/src/features/pet/petGifts.ts` | Каталог подарков `PET_GIFTS` + константы (ключ хранилища, стартовый баланс, лимит эффектов, тексты) |
| `apps/launcher/src/features/pet/usePetState.ts` | Хук: баланс, счётчики, очередь эффектов, localStorage, reset |
| `apps/launcher/src/features/pet/PetWidget.tsx` | Виджет: «аквариум», настроение рыбы, слои эффектов, сброс |
| `apps/launcher/src/features/pet/GiftPanel.tsx` | Панель кнопок-подарков (рендер из конфига) |
| `apps/launcher/src/index.css` | Keyframes: `pet-bob`, `pet-pellet-fall`, `pet-bubble-rise`, `pet-zap-flash`, `pet-crown-drop`, `pet-heart-float`, `pet-toast-fade` |

Встраивание — одна строка `<PetWidget />` в `LibraryPage.tsx`.

## Состояние

`localStorage` → ключ `chlauncher.pet.state.v1`:
`{ totalGifts, coins, lastGift, counts }`. Стартовый баланс — 100 монет.
Активные эффекты не сохраняются (это рантайм, максимум 3 слоя одновременно —
новый вытесняет самый старый). Кнопка «Сбросить питомца» — двухшаговая
(первый клик «вооружает» на 2.5с).

## Своя гифка

Кнопка «Свой GIF» в шапке виджета открывает выбор файла
(GIF/WebP/APNG/PNG, ≤8 МБ). Файл хранится как blob в IndexedDB —
не в localStorage (квота ~5МБ) и не на диске в явном виде; показывается
через `URL.createObjectURL`. «Стандартная» возвращает встроенную рыбу.
Картинка сохраняется между запусками и не трогается кнопкой «Сбросить
питомца» (сбрасывает только прогресс).

## Подарки

| Подарок | Цена | Эффект | Длительность |
|---|---|---|---|
| 🐟 Корм | 1 | падающие хлопья | 2с |
| 🫧 Пузырь | 2 | фонтан пузырей | 2.5с |
| ⚡️ Молния | 5 | разгон + вспышки скорости | 2.5с |
| 👑 Корона | 10 | корона + золотое сияние | 6с |
| ❤️ Сердце | 3 | сердечки + «счастливое» покачивание | 2.2с |

Монеты виртуальные, не привязаны к оплате. При нехватке баланса кнопка
неактивна (`disabled`), плюс сторожевой `return false` в `sendGift`.

## Как добавить новый подарок

1. Добавь запись в `PET_GIFTS` (`petGifts.ts`) — `id`, `title`, `icon`,
   `price`, `durationMs`, `hint`, `effect`. Если эффект уже есть в
   `PetEffect` — всё, готово.
2. Для НОВОГО эффекта:
   - добавь его в union `PetEffect` (`types.ts`),
   - добавь запись в `EFFECT_COMPONENTS` (`PetWidget.tsx`) — слой с
     CSS-анимированными элементами,
   - добавь keyframes в `index.css` (правило: `pointer-events: none`,
     длительность 1.5–3с, `forwards` в исходное).
3. Никаких правок UI-логики — кнопка, цена, disabled-state и счётчик
   подставятся из конфига автоматически.

## Расширение

Слой `usePetState` изолирован: позже `sendGift` можно связать с
`packages/game-sdk` (события реальных донатов) или с бэкенд-балансом, не
трогая виджет. Подарки сейчас НЕ являются покупками — для реальных
платежей потребуется отдельная спека.
