ГДЕ ВЗЯТЬ ЕЩЁ ГОЛОСА (PIPER — реально разные люди)
---------------------------------------------------------------------

В «Озвучке» выбери Движок → Piper → «Скачать Piper» (один раз, ~22 МБ).

1) КАТАЛОГ (встроенный): кнопка «Скачать» у каждой модели.
   RU-модели читают русский чат — Дмитрий, Денис, Ирина, Милена, Руслан.
   EN-модели — для шаблонов/шуток (русский текст НЕ читают).

2) СВОИ ГОЛОСА (персонажи игр, комьюнити-модели):
   - Вставь ПРЯМУЮ ссылку на файл *.onnx в поле «Прямая ссылка на *.onnx»
     → кнопка «По ссылке». Конфиг *.onnx.json подтянется сам.
   - Или кнопка «Папка» → скопируй туда пару файлов:
       имя.onnx  +  имя.onnx.json
     Любая Piper-модель подхватится автоматически — появится в списке
     с пометкой «свой голос» и доступна везде (основной голос, правила,
     белый список, озвучка подарков).

   Где искать модели:
   - официальный каталог: huggingface.co/rhasspy/piper-voices (tree/v1.0.0)
   - поиск на Hugging Face по слову «piper» — там комьюнити-голоса
     (персонажи игр, стримеров и т.п.). Каждой модели нужны ДВА файла:
     model.onnx и model.onnx.json — качай оба по кнопке Download.

3) Кнопка корзины у скачанной модели — удаляет её с диска.

ГОЛОСА ПЕРСОНАЖЕЙ (RVC — реальные голоса людей)
---------------------------------------------------------------------

В папке tools\rvc-server\models\ уже лежат 6 голосов:
  ALBLAK52, DosyeV2, BigBabyTape, Gensyha, kizaru, stariy_bog

Как это работает: любой движок читает текст, потом RVC-сервер
превращает звук в голос персонажа. Нужен Python 3.11 — один раз.

УСТАНОВКА (один раз):
  1) Установи Python 3.11 с python.org (галка "Add python.exe to PATH").
  2) Двойной клик:  tools\rvc-server\УСТАНОВИТЬ_RVC.cmd
     (~3-4 ГБ зависимостей — torch, fairseq, rvc-python; жди до "ГОТОВО").

ЗАПУСК:
  - После установки ЗАПУСТИТЬ_ВСЁ.cmd сам поднимает третье окно "RVC :7865".
  - Или вручную: tools\rvc-server\ЗАПУСТИТЬ_RVC.cmd.
  - В «Озвучке» в списке голосов появятся записи "...· RVC-голос"
    (сервер должен быть запущен). Работают везде: основной голос,
    правила, белый список, озвучка подарков.
  - Сервер не запущен → голоса RVC не видны в списке; на строке
    статуса видно "сервер не запущен".

СВОИ МОДЕЛИ: закинь в tools\rvc-server\models\<Имя>\ файлы .pth + .index —
голос появится сам при запущенном сервере.

ПРИМЕЧАНИЯ:
  - На CPU конверсия одной фразы занимает 1-5 сек — при большом потоке
    комментариев смотри кулдауны/очередь.
  - Для GPU (NVIDIA): ставь CUDA-сборку torch и RVC_DEVICE=cuda:0.
=== ГОЛОСА: Silero + Gemini ===

Голосовой сервер (RVC :7865) теперь умеет два дела:
- /convert — конвертирует речь в голоса персонажей (RVC-модели)
- /tts — локальные нейроголоса Silero (aidar, eugene, baya, kseniya, xenia)

Silero — бесплатные русские нейроголоса (уровень Яндекса), работают
локально, без ключей и VPN. В списках голосов: «aidar · Silero» и т.д.

Gemini — 30 облачных голосов Google (те же, что в Echo). Нужен:
1) включённый VPN (API геоблокирован),
2) ключ Google AI Studio (aistudio.google.com → Get API key).
В лаунчере: Озвучка → Движок → Gemini → вставить ключ → голоса
«Имя · Gemini» появятся во всех списках.
