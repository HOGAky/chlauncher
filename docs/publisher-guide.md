# Publisher Guide — как добавить свою игру в chlauncher

Документ для сторонних разработчиков (коллабов), поставляющих игры в
каталог лаунчера. Всё описанное работает через публичный API —
самостоятельно, без участия админа в повседневном цикле.

## 0. Получение доступа

1. Зарегистрируйся в лаунчере обычным аккаунтом.
2. Попроси админа выдать роль `publisher`:
   - админка лаунчера → Пользователи → роль `publisher`, **или**
   - `node tools/grant-admin.mjs <email> publisher` на сервере.
3. Для CLI-публикации аккаунт должен быть привязан к устройству
   (войди один раз через лаунчер) либо передавай `--hwid`.

## 1. Два вида поставки

| | `kind=game` (standalone) | `kind=adapter` (мод) |
|---|---|---|
| Что это | Свой exe, который лаунчер качает и запускает | Мод к чужой игре (GTA, Valheim…), живёт внутри той игры |
| Рукопожатие | `--port` + токен из stdin → `hello` | `hello_adapter` с постоянным `adapter_key` |
| Окно | Своё (лаунчер задаёт флаги окна) | Внутри сторонней игры |
| События | Одинаковый поток `event` | + опциональный `ack` выполнения |

Протокол один и тот же для обоих — `docs/protocol.md`. Rust-играм
проще всего через `packages/game-sdk` (`init_or_exit()` → `poll()` →
`is_alive()`); на любом другом движке/языке протокол реализуется руками —
это ~100 строк (см. `tools/adapter-example/index.js` на чистом Node).

### Что получает игра

Уже замапленные триггером стримера события — игра **не** общается с
TikTok напрямую:

```jsonc
{ "type": "event", "event": {
    "source": "tiktok" | "donationalerts" | "simulator",
    "event_kind": "gift" | "like" | "comment" | "donation" | "system",
    "user": "viewer", "action_command": "spawn_enemy",
    "amount": 1, "raw_name": "Rose", "event_id": "uuid" } }
```

`action_command` — строка из маппера триггеров; словарь команд игра
задаёт сама (для адаптеров — в `adapter_manifest`, для standalone —
документируй в описании игры, стример вбивает команды руками).

**Свой таймер/UI внутри игры** — рисуется самой игрой в её окне,
никаких ограничений. Если нужен именно оверлей *внутри лаунчера*
(как встроенные Gift Tower / Таймер) — это отдельная история: отдай
HTML/код нам, встраиваем в релиз лаунчера.

## 2. Требования к билду

- **zip** ≤ `MAX_BUILD_SIZE` (по умолчанию 2 ГБ), внутри — exe с именем
  `executable_name` из записи игры; версии семверные и не повторяются.
- **Windows x64**, без внешних CRT-зависимостей (статическая линковка;
  `WebView2Loader.dll` допустим рядом с exe).
- Игра **обязана** завершаться при разрыве сокета или отсутствии
  heartbeat 150 с (SDK делает это сам через `is_alive()`).
- Токен приходит **только в stdin**, не в argv — не логируй его.

## 3. Цикл публикации

```bash
# разово: создать черновик
node tools/publisher-game.mjs --server https://api.<домен> \
  --email dev@x.com --password … create \
  --slug my-timer --title "My Timer" --exe my-timer.exe

# каждый билд:
node tools/publisher-game.mjs … upload \
  --slug my-timer --version 1.2.0 --zip dist/my-timer-1.2.0.zip \
  --changelog "что нового"

# отправить на ревью:
node tools/publisher-game.mjs … submit --slug my-timer --version 1.2.0

# или всё одной командой (create если нет → upload → submit):
node tools/publisher-game.mjs … release \
  --slug my-timer --title "My Timer" --exe my-timer.exe \
  --version 1.2.0 --zip dist/my-timer-1.2.0.zip

# статус своих игр/ревью:
node tools/publisher-game.mjs … list
```

После `submit` билд попадает в очередь ревью (`pending`). Админ в
админке аппрувит (игра мгновенно в каталоге) или реджектит с feedback —
он виден в `list`. Одна игра — одна активная заявка; отозвать:
`POST /api/publisher/submissions/:id/cancel`.

## 4. Локальная отладка до публикации

- Подними `apps/server` и лаунчер локально (см. README).
- Админ может залить билд напрямую через `tools/publish-game.mjs`
  (admin-эндпоинты без ревью) — удобно для первого прогона.
- События тестируй **симулятором** лаунчера (страница «Симулятор») —
  игра получает их как настоящие TikTok-события.
- Watchdog: убей соединение → игра должна выйти сама; launcher убьёт
  процесс через 15 с, если не было `hello`.

## 5. Деньги и защита

- Билды отдаются только аккаунтам с активной подпиской —
  защита на сервере, пиратство зипом не лечит.
- `is_free` в записи игры = доступна и на free-тарифе.
- Токен запуска одноразовый, 15-секундный handshake — игру вне
  лаунчера не запустить штатно.
